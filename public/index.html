Twitch Integration

Connect your Twitch channel for live card drops

Create a Channel Points reward in your Twitch dashboard and paste the ID here, or let us create one for you automatically.

We'll create a reward called "Open a Card Pack" that can be redeemed once per stream. You can tweak the cost and limits in your Twitch Creator Dashboard.

Optional: Second reward for card battles

How to get your Reward ID:

  1. Go to your Twitch Creator Dashboard
  2. Navigate to Channel Points → Rewards
  3. Create a new reward (e.g., "Open a Card Pack")
  4. Copy the Reward ID from the URL or API response
